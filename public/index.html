              Your first 5 minutes

              1. Check the setup below. Draft mode (no model key) works for a dry run; add a Cursor key for real answers.
              2. Sign in under Account so your agents, automations and environments are saved.
              3. Create an environment for the client or program (sidebar → + New environment). Each environment keeps its own rooms, agents and memory.
              4. Bring in agents. Import the Axian Squad under Team & agents, or copy a built-in agent and edit it. Arrange them in the Automation builder.
              5. Connect sources (Confluence, Figma, GitHub) in Sprint sources, paste the requirement, and start the kickoff.
              6. Approve as you go. Agents pause for your OK between steps, and every write to Jira, Confluence, Figma, GitHub or Jenkins waits for you to press Allow.
